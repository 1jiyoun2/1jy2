# CLASS BOARD (시연용 골격)
기존 GitHub Pages 사이트의 `/class-board/` 경로에서 실행하는 수업 게시판 초기 화면입니다.

- 학생: 수업 목록, 주제별 게시판, 이름·의견 입력 UI, 예시 의견 카드
- 교사: 관리자 대시보드의 시각적 골격
- 지금은 **데모**이며 작성 내용을 서버에 전송하거나 저장하지 않습니다.
- 관리자 로그인·게시판 생성·삭제·IP 수집은 실제로 활성화되어 있지 않습니다.
