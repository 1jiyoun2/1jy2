Python 기반 문제 해결 구현

Python · Problem Solving Project

문제 해결 과정을 실제 Python 프로그램으로 구현하는 프로젝트이다. 2학기에는 입출력·변수·조건문·반복문을 다시 실습한 뒤 프로젝트로 연결하였다.

문제 선택
→ 해결 흐름 설계
→ 필요한 입력과 출력 정리
→ Python 구현
→ 실행과 테스트
→ 오류 수정
→ 결과 확인
활용 요소내용
입출력사용자에게 필요한 값을 입력받고 결과를 출력
변수문제 해결 과정에서 필요한 값을 저장하고 변경
조건문상황에 따라 서로 다른 처리를 수행
반복문반복되는 작업을 효율적으로 처리
테스트와 수정여러 입력으로 실행해 문제점을 찾고 코드를 개선

Python 문법을 따로 암기하는 데서 끝내지 않고, 앞서 설계한 해결 절차를 실제 프로그램으로 구현하는 경험을 중심으로 운영하였다.
