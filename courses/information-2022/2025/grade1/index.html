수업 운영 방향

1학기에는 디지털 정보 표현, 데이터 시각화, Python 기초, 피지컬 컴퓨팅과 알고리즘 실습을 연결하였다. 2학기에는 네 개의 수행평가를 중심으로 문제 해결, 디지털 사회와 진로, Python 구현, 데이터 분석을 각각 프로젝트 형태로 확장하였다.

교과서 4단원 인공지능은 2학년의 「인공지능 기초」 과목에서 보다 깊게 다루도록 직접적인 단원 수업은 최소화하였다. 대신 인공지능 생성 코드를 디버깅하거나 프로젝트 과정에서 인공지능 도구를 활용하는 등, 다른 단원의 문제 해결 활동 속에서 인공지능 활용 경험을 자연스럽게 포함하였다.
