기계학습 모델과 성능 분석

Classification · Prediction · Regression · Evaluation

전처리한 데이터를 바탕으로 분류와 예측 모델을 실행하고, 모델이 만든 결과를 실제 데이터와 비교하여 해석하는 활동으로 확장하였다.

분류와 예측

활동수업에서 본 관점
아이리스 분류여러 속성을 이용해 품종을 구분하는 분류 문제 경험
예측 모델입력 특성을 이용해 결과값을 예측하는 모델의 기본 흐름 확인
선형 회귀독립변수와 종속변수의 관계를 선형 모델로 표현하고 예측값 생성

모델링을 위한 변수 선택

학생들은 데이터의 여러 속성 중 어떤 값을 종속변수로 둘 것인지 정하고, 어떤 독립변수가 그 값을 예측하는 데 관련이 있을지 설명하였다. 필요하면 학습에서 제외할 속성을 정하고 그 이유도 데이터와 문제 상황에 연결하였다.

성능 분석

모델 실행 이후에는 예측값만 확인하지 않고 실제값과 예측값을 비교하였다. 산점도로 두 값을 함께 나타내고, 실제값과 예측값이 같아지는 기준선을 함께 표시해 모델의 예측이 어느 정도 맞는지 시각적으로 해석하였다.

데이터 확인
→ 독립변수와 종속변수 선택
→ 학습용/평가용 데이터 구성
→ 모델 학습
→ 예측
→ 실제값과 예측값 비교
→ 성능과 한계 해석

이 영역에서는 fit()이나 predict()를 외워 작성하는 능력보다, 어떤 데이터를 사용해 무엇을 예측했고 결과가 어느 정도 타당한지 설명하는 능력을 중심으로 수업하였다.
