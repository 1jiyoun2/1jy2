컴퓨터 비전과 인공지능 프로젝트

Computer Vision · Project

분류와 모델 성능 분석을 학습한 뒤 이미지 데이터를 입력으로 사용하는 컴퓨터 비전으로 범위를 확장하고, 이를 인공지능 프로젝트로 연결하였다.

컴퓨터 비전 실습

교과서의 쓰레기 분리배출 이미지 분류 사례를 활용하여 이미지 파일, 학습된 모델 파일, Colab 코드를 함께 실행해 보았다. 코드 전체를 처음부터 구현하기보다 제공된 모델과 코드를 실행하고 입력 이미지에 따라 분류 결과가 어떻게 나오는지 확인하였다.

프로젝트 흐름

차시활동
1차시 · 기획해결하고 싶은 문제와 인공지능 활용 방법을 정하고 프로젝트 방향 설계
2~3차시 · 구현데이터와 모델을 이용해 결과물을 구현하고 실행 과정 점검
4차시 · 최종결과를 정리하고 모델의 동작, 한계, 개선 가능성을 설명

결과보다 과정 보기

프로젝트에서는 모델이 한 번 맞게 분류했다는 사실보다, 어떤 데이터로 학습했는지, 어떤 상황에서 오분류가 생기는지, 결과를 실제 상황에 적용하려면 무엇을 더 고려해야 하는지를 살펴보았다.

예측 확률이나 오분류 사례를 통해 학습 데이터의 양과 구성, 촬영 환경, 배경과 같은 조건이 모델 결과에 영향을 줄 수 있음을 확인하고, 결과물을 더 발전시킬 방향을 생각하도록 하였다.

프로젝트의 목적은 인공지능 모델을 처음부터 구현하는 것이 아니라, 문제를 정하고 적절한 데이터와 모델을 활용한 뒤 결과와 한계를 분석하는 전 과정을 경험하는 데 두었다.
