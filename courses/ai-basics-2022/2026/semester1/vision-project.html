컴퓨터 비전과 AI 활용 프로젝트

Computer Vision · Project

분류와 모델 성능 분석을 학습한 뒤 이미지 데이터를 입력으로 사용하는 컴퓨터 비전으로 범위를 확장하고, 이를 AI 활용 프로젝트로 연결하였다.

컴퓨터 비전 실습

교과서의 쓰레기 분리배출 이미지 분류 사례를 활용하여 이미지 파일, 학습된 모델 파일, Colab 코드를 함께 실행해 보았다. 코드 전체를 처음부터 구현하기보다 제공된 모델과 코드를 실행하고 입력 이미지에 따라 분류 결과가 어떻게 나오는지 확인하였다.

프로젝트 흐름

차시활동
1차시 · 기획해결할 문제를 정하고 문제의 중요성, 프로젝트 목표, 사용할 인공지능 기술, 예상 결과물, 성공 기준, 예상 한계와 윤리적 고려사항, 추진 계획까지 구체화
2~3차시 · 구현기획 내용을 바탕으로 데이터·모델·인공지능 도구를 활용해 결과물을 구현하고 테스트와 수정 반복
4차시 · 최종완성한 결과물을 정리하고 실제 동작, 목표 달성 정도, 모델 또는 시스템의 한계, 개선 방향을 설명

1차시 · 프로젝트 기획

프로젝트의 핵심은 바로 구현을 시작하는 것이 아니라, 인공지능 기술이 필요한 실제 문제를 먼저 정의하고 해결 과정을 설계하는 데 두었다.

기획 요소확인한 내용
문제 정의무엇이 문제인지, 왜 해결이 필요한지 구체적으로 설명
문제의 중요성개인·학교·지역사회·사회 전체에 미치는 영향과 해결 필요성 설명
프로젝트 목표인공지능을 활용해 최종적으로 달성하려는 목표 설정
인공지능 기술 선택이미지 인식·음성 인식·자연어 처리·추천·기계학습 모델 등 문제에 적합한 기술 또는 방법 선택
데이터 계획데이터 분석 프로젝트의 경우 사용할 데이터의 출처, 주요 속성, 예측·분류 대상까지 사전에 설계
예상 결과물웹사이트·앱·게임·챗봇·이미지 분류 등 결과물의 형태를 구체화
성공 기준정상 동작 여부, 분류·예측 결과, 사용자 기능 등 성공 여부를 판단할 기준 설정
한계와 위험데이터 확보, 구현 난이도, 시간, 성능, 사용자 테스트 등 예상되는 어려움 분석
사회적·윤리적 영향편의 향상뿐 아니라 오분류, 잘못된 정보, 개인정보 등 실제 사용 시 발생할 수 있는 영향 검토
추진 계획자료 수집 → 구현 → 테스트 → 수정처럼 2~3차시의 개발 순서를 스스로 계획

데이터 분석 프로젝트를 선택한 학생은 데이터 링크를 먼저 확보하고 주요 변수와 예측·분류 대상을 정하도록 하여, 이후 구현이 단순 코드 실행으로 끝나지 않도록 하였다.

결과보다 과정 보기

프로젝트에서는 모델이 한 번 맞게 분류했다는 사실보다, 어떤 데이터로 학습했는지, 어떤 상황에서 오분류가 생기는지, 결과를 실제 상황에 적용하려면 무엇을 더 고려해야 하는지를 살펴보았다.

예측 확률이나 오분류 사례를 통해 학습 데이터의 양과 구성, 촬영 환경, 배경과 같은 조건이 모델 결과에 영향을 줄 수 있음을 확인하고, 결과물을 더 발전시킬 방향을 생각하도록 하였다.

프로젝트는 이 과목의 핵심 종합 활동이었다. 인공지능 모델을 처음부터 구현하는 것보다, 문제를 정의하고 적합한 인공지능 기술과 데이터를 선택한 뒤 성공 기준과 윤리적 영향을 포함해 기획하고, 구현·테스트·분석·개선까지 이어지는 전 과정을 경험하는 데 두었다.
