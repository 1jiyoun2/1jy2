교과 내용 구성

2022 개정 인공지능 기초 교과의 학습 내용을 실제 수업 운영 흐름에 맞추어 요약

Ⅰ. 인공지능과 문제 해결

영역학습 내용
탐색초기 상태와 목표 상태, 탐색 공간, 이웃 노드, 탐색 경로
휴리스틱목표에 가까운 상태를 우선 선택하기 위한 평가 기준과 최상 우선 탐색
지식과 추론사실과 규칙을 이용하여 새로운 판단에 도달하는 과정

Ⅱ. 데이터와 인공지능

영역학습 내용
데이터 이해CSV 데이터 구조 확인, 속성과 값의 의미 파악
데이터 전처리중복값·결측값·이상값 확인, 범주형 값 변환, 불필요한 속성 제거
데이터 시각화산점도·상자 그림 등을 이용한 분포와 관계 분석
속성 선택문제 상황에 필요한 독립변수와 종속변수를 정하고 선택 이유 설명

Ⅲ. 기계학습

영역학습 내용
분류아이리스 데이터를 이용한 K-최근접 이웃 분류와 혼동 행렬·정확도 확인
예측과 회귀선형 회귀 모델을 이용한 예측, 기울기·절편·평균제곱오차·결정계수 해석
딥러닝 이진 분류범주형 데이터 인코딩, 학습/평가 데이터 분리, 은닉층과 출력층 구성, 손실과 정확도 확인
모델 성능 분석실제값과 예측값 비교, 평가 지표와 학습 과정 그래프를 이용한 모델 해석

Ⅳ. 인공지능 활용과 프로젝트

영역학습 내용
컴퓨터 비전이미지와 학습된 모델을 활용한 분류 실습
인공지능 프로젝트문제 기획, 데이터·모델 활용, 구현, 결과 분석, 한계와 개선 방향 정리

Ⅴ. 인공지능과 사회

영역학습 내용
인공지능 윤리편향, 안전성, 책임, 실제 사회에 적용할 때의 영향과 주의점
성찰프로젝트와 데이터 분석에서 발견한 한계와 개선 가능성을 자신의 활동과 연결하여 설명

교과서 원문을 재게시하지 않고, 2026학년도 실제 수업에서 다룬 내용과 활동을 중심으로 교과 구조를 요약하였다.
