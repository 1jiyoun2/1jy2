클래스

텍스트 RPG 코드를 읽기 위한 최소한의 개념

2022 개정 삼양 프로그래밍 교과서에서는 클래스를 정규 학습 내용으로 다루지 않는다. 이 페이지는 텍스트 RPG 코드를 읽을 때 필요한 정도만 설명한다.

클래스는 무엇인가?

관련된 데이터와 기능을 하나의 틀로 묶어 표현하는 방법이다. 여기서는 클래스를 직접 설계하는 방법보다, 이미 작성된 코드에서 어떤 값과 기능이 한 묶음으로 관리되는지 읽는 데 초점을 둔다.

간단한 예

class Player:
    def __init__(self, name):
        self.name = name
        self.hp = 100

    def show_status(self):
        print(self.name, self.hp)

player = Player("용사")
player.show_status()
코드읽는 방법
class Player:플레이어와 관련된 값과 기능을 묶는 틀
__init__플레이어가 처음 만들어질 때 필요한 값을 준비하는 부분
self.name각 플레이어가 가지고 있는 이름 값
show_status()플레이어 상태를 보여 주는 기능
Player("용사")Player 틀을 이용해 실제 플레이어 하나를 만드는 부분

상속, 캡슐화, 다형성 등 객체 지향 프로그래밍의 세부 개념은 이 수업의 학습 범위로 다루지 않는다.
