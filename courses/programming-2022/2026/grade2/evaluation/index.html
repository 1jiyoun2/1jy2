평가 개요

수행평가는 3개 영역으로 구성되어 있습니다. 각 평가에서 확인하는 역량과 논술형 포함 여부만 간단히 안내합니다.

구분평가 목적 및 형태
1번 평가 문제와 요구 사항을 분석하고, 프로그램을 설계·구현·테스트하는 능력 확인
논술형: 포함
2번 평가 코드의 실행 과정과 결과를 분석하고, 구조와 동작 원리를 설명하는 능력 확인
논술형: 포함
3번 평가 문제 해결 알고리즘을 구성하고 프로그래밍 요소를 적용하여 구현하며, 실행 결과와 해결 과정을 설명하는 능력 확인
논술형: 포함

평가 일정과 구체적인 운영 사항은 학교에서 안내하는 평가계획을 확인해 주세요.
