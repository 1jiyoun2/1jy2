수업 방향

Python 문법을 개별 기능으로만 익히는 데 그치지 않고, 실제 프로그램 안에서 각 개념이 어떻게 연결되는지 확인하고 직접 설계·구현·테스트하는 경험으로 확장한다.

언어Python
주요 흐름Python 기초 문법 → 프로그램 이해 → 코드 분석 및 구현 → 컴퓨터 내부 표현 → 프로그램 개발 프로젝트
주요 학습 요소자료형·입출력, 산술·비교·논리·비트 연산, 선택·반복 구조, 함수·매개변수·반환값, 파일 처리, 예외 처리, 알고리즘, 테스트
기록 방식수업 자료와 실제 수업 진행 기록을 함께 남긴다.
