4. 함수

Built-in · Library · User-defined · Parameter · Return

함수의 종류

종류수업에서 읽는 방법
내장 함수print(), len(), max()처럼 바로 사용할 수 있는 함수
라이브러리 함수math 같은 모듈을 먼저 불러온 뒤 사용하는 함수
사용자 정의 함수def로 필요한 기능을 직접 정의한 함수

정의와 호출

함수는 정의했다고 바로 실행되지 않는다. 함수 이름과 괄호를 이용해 호출할 때 내부 코드가 실행된다.

매개변수와 반환값

함수 실행에 필요한 값은 매개변수로 전달하고, 처리한 결과를 호출한 위치에서 다시 사용하려면 return으로 반환한다.

지역 변수와 전역 변수

함수 안에서 만들어진 지역 변수와 함수 바깥의 전역 변수는 사용할 수 있는 범위가 다르다.

확인하기

  1. 함수 정의 부분과 실제 호출 부분을 각각 찾아 표시한다.
  2. 인자로 전달된 값이 어떤 매개변수에 저장되는지 추적한다.
  3. return 값이 호출 위치에서 어떻게 다시 사용되는지 확인한다.
  4. 같은 이름의 변수가 함수 안과 밖에서 사용될 때 범위를 구분한다.
