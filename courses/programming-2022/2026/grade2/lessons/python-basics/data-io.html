자료형 변환

int(), float(), str(), repr(), bool()을 이용해 필요한 자료형으로 바꾼다. 문자와 정수 코드의 변환에는 ord(), chr()도 사용할 수 있다.

문자는 컴퓨터 내부에서 문자 코드로 저장되므로 ASCII와 유니코드의 개념도 함께 확인한다.

변수 이름과 주석

변수 이름은 영문자·숫자·_를 사용할 수 있고, 숫자로 시작할 수 없다. 대문자와 소문자를 구분하며 예약어나 내장 함수 이름은 변수 이름으로 사용하지 않는다. 코드 설명은 # 주석으로 남길 수 있다.

출력 형식

print()의 sep과 end를 이용하면 값 사이의 구분 문자와 출력 마지막 문자를 바꿀 수 있다. \n은 새 줄로 바꾸는 데 사용한다.

리스트와 인덱스

확인하기

  1. input()의 결과는 기본적으로 어떤 자료형인지 확인해 본다.
  2. "10"과 10의 차이를 자료형과 연산 결과로 설명해 본다.
  3. 공백으로 입력한 세 단어를 리스트에 저장한 뒤 인덱스를 이용해 순서를 바꾸어 출력해 본다.
  4. sep과 end를 바꾸었을 때 출력 결과가 어떻게 달라지는지 확인한다.
