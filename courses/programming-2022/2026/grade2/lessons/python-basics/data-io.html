1. 데이터 입출력

Data Types · Variables · Input · Output

자료형

구분수업에서 확인하는 내용
정수소수점이 없는 수
실수소수점을 포함하는 수
문자열문자를 하나 이상 이어서 표현한 값
논릿값True, False

자료형 변환

int(), float(), str(), bool()을 이용해 필요한 자료형으로 바꾼다. 문자와 정수 코드의 변환에는 ord(), chr()도 사용할 수 있다.

입력과 변수

여러 값 입력하기

리스트와 인덱스

확인하기

  1. input()의 결과는 기본적으로 어떤 자료형인지 확인해 본다.
  2. "10"과 10의 차이를 자료형과 연산 결과로 설명해 본다.
  3. 공백으로 입력한 세 단어를 리스트에 저장한 뒤 인덱스를 이용해 순서를 바꾸어 출력해 본다.
