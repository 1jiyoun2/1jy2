3. 제어 구조

Sequence · Selection · Iteration

순차 구조와 코드 블록

코드를 위에서 아래로 순서대로 실행하는 것이 기본 흐름이다. Python에서는 같은 크기의 들여쓰기로 하나의 코드 블록을 구분하므로, 선택·반복 구조를 읽을 때 들여쓰기 범위를 함께 확인한다.

선택 구조

if, elif, else를 이용해 조건에 따라 실행할 코드를 선택한다.

반복 구조

for는 정해진 범위나 데이터의 항목을 순서대로 반복할 때, while은 조건이 참인 동안 반복할 때 사용한다.

continue와 break

continue는 현재 반복의 남은 부분을 건너뛰고 다음 반복으로 이동하며, break는 반복 자체를 끝낸다.

중첩 반복 구조

반복 구조 안에 다른 반복 구조를 넣어 행·열처럼 여러 값을 조합하여 처리할 수 있다.

확인하기

  1. 같은 반복 작업을 for와 while로 각각 표현해 본다.
  2. 조건문의 들여쓰기가 달라지면 실행 범위가 어떻게 달라지는지 확인한다.
  3. continue와 break가 반복 흐름을 어떻게 다르게 바꾸는지 비교한다.
  4. 중첩 반복에서 바깥쪽 반복 1회당 안쪽 반복이 몇 번 실행되는지 추적한다.
