3. 제어 구조

Sequence · Selection · Iteration

순차 구조

코드를 위에서 아래로 순서대로 실행하는 기본 흐름이다. 입력 → 처리 → 출력과 같이 처리 순서를 추적한다.

선택 구조

if, elif, else를 이용해 조건에 따라 실행할 코드를 선택한다.

반복 구조

for는 정해진 범위나 데이터의 항목을 순서대로 반복할 때, while은 조건이 참인 동안 반복할 때 사용한다.

중첩과 반복 중단

선택 구조와 반복 구조는 서로 안에 넣어 사용할 수 있다. 반복 도중 조건을 만족하면 break로 반복을 끝낼 수도 있다.

확인하기

  1. 같은 반복 작업을 for와 while로 각각 표현해 본다.
  2. 조건문의 들여쓰기가 달라지면 실행 범위가 어떻게 달라지는지 확인한다.
  3. break가 실행되는 조건과 반복이 끝난 뒤 실행될 코드를 추적한다.
