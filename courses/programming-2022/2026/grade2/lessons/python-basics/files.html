5. 파일 처리

File · open() · read() · write() · TXT · CSV

파일 처리 흐름

파일 이름과 모드를 지정해 파일을 열고 → 데이터를 읽거나 쓰고 → 작업이 끝나면 파일을 닫는 흐름으로 처리한다.

주요 파일 모드

모드의미
r읽기. 대상 파일이 필요하다.
w쓰기. 기존 파일이 있으면 새 내용으로 덮어쓴다.
x새 파일 생성. 같은 이름의 파일이 있으면 생성하지 않는다.
a파일의 마지막에 내용을 추가한다.
b바이너리 모드
t텍스트 모드
+읽기와 쓰기를 함께 사용하는 업데이트 모드

TXT 파일 쓰기와 읽기

write()로 문자열을 기록하고 read()로 전체 내용을 읽을 수 있다. 텍스트 파일에서는 encoding="utf-8"처럼 문자 인코딩도 지정할 수 있다.

readline()과 seek()

readline()은 한 줄씩 읽고, seek()는 파일에서 읽고 쓸 위치를 이동할 때 사용한다.

추가 모드

CSV 파일

CSV는 한 줄의 여러 값을 쉼표로 구분해 저장하는 텍스트 형식이다.

확인하기

  1. 없는 파일을 r 모드로 열 때와 w 모드로 열 때의 차이를 확인한다.
  2. w와 a가 기존 파일 내용에 미치는 차이를 설명한다.
  3. read()와 readline()의 차이를 실행 결과로 확인한다.
  4. seek(0)을 실행한 뒤 다시 읽으면 어떤 결과가 나오는지 확인한다.
  5. CSV 한 줄을 읽은 뒤 split(",")한 결과를 확인한다.
