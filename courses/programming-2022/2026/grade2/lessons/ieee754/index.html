IEEE 754

Floating-point representation and implementation

10진수 실수가 컴퓨터 내부에서 어떻게 표현되는지 살펴보고, 변환 절차를 단계별 알고리즘으로 정리한 뒤 Python 코드로 구현한다.

학습 흐름

단계내용
문제 분해부호, 정수부, 소수부, 정규화, 지수부, 가수부로 변환 과정을 나누기
알고리즘각 단계의 입력·처리·출력을 순서대로 표현
코드 구현작은 기능 단위로 구현하고 전체 변환 과정으로 결합
실행 결과 분석입력값에 따른 실행 결과를 확인하고 예상과 다른 경우 원인 분석
수정발견한 문제를 코드와 알고리즘 수준에서 수정

수업 기록에서 확인된 점

코드 구현에 예상보다 시간이 많이 필요한 경우가 있어, 구현 과정과 실행 결과 분석을 한 차시에 모두 처리하기보다 코드 분석과 결과 분석을 분리하여 진행하는 방식으로 수업을 조정하였다.
