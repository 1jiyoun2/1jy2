IEEE 754

Floating-point representation and implementation

10진수 실수가 컴퓨터 내부에서 어떻게 표현되는지 살펴보고, 변환 절차를 단계별 알고리즘으로 정리한 뒤 Python 코드로 구현한다.

삼양 프로그래밍 교과서에는 실수가 IEEE 754 방식에 따라 부호·지수부·가수부로 저장된다는 내용이 간단히 제시되어 있다. 이 페이지는 그 내용을 실제 수업에서 다룬 수준으로 확장하여 정리한 것이다.

단정도 32비트 구조

부분역할
부호 비트 · 1비트양수와 음수를 구분
지수부 · 8비트정규화 과정에서 얻은 실제 지수에 bias 127을 더해 저장
가수부 · 23비트정규화된 1.xxxxx에서 맨 앞의 1을 제외한 비트를 저장

수업에서 사용한 구현 흐름

단계처리
1. 입력 처리수업에서 사용할 입력 범위를 확인하고 부호 비트를 준비
2. 정수 부분 변환int_bits에 정수 부분의 2진 비트를 저장
3. 소수 부분 변환frac_bits에 소수 부분의 2진 비트를 저장
4. 정규화first_one을 찾고 real_exp, normalized_bits 생성
5. 지수부stored_exp = real_exp + 127 후 8비트 exponent_bits 생성
6. 가수부normalized_bits를 이용해 23비트 mantissa_bits 생성
7. 최종 결합부호 + 지수부 + 가수부 순으로 연결하여 ieee754 완성

수업용 구현 코드

아래 코드는 실제 수업과 후속 코드 분석에서 사용한 기준 코드의 흐름을 그대로 두고, 공개 아카이브에서 읽기 쉽도록 설명 주석을 추가한 버전이다.

이 코드는 IEEE 754를 처리하는 유일한 정답이나 범용 변환기가 아니다. 학생이 각 처리 단계를 직접 추적할 수 있도록 조건과 구현 방식을 단순화한 교육용 코드다. 수업에서는 0보다 크고 16보다 작은 양의 실수, 2진수로 유한하게 표현되는 소수, 가수 후보가 23비트를 넘지 않는 경우만 다룬다.

수업 예시 · 10.625 추적

값결과
10진수 입력10.625
2진수1010.101₂
정규화1.010101₂ × 2³
부호 비트0
저장 지수130
지수부10000010
가수부01010100000000000000000
최종 32비트01000001001010100000000000000000

한 입력값을 끝까지 따라가면서 “지금 만든 값이 다음 단계에서 어디에 쓰이는가?”를 계속 확인한다.

연습 · 0.15625

0.15625를 같은 코드에 입력하고 다음 값을 직접 추적한다.

  1. sign_bit
  2. frac_bits
  3. real_exp
  4. stored_exp와 exponent_bits
  5. mantissa_bits
  6. 최종 IEEE 754 32비트

완성 코드를 외우는 것이 아니라, 각 값이 어디에서 만들어지고 다음 단계에서 어떻게 사용되는지를 설명하는 것이 목적이다.
