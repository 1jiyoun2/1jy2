텍스트 RPG 모듈별 코드

15 modules · complete teaching source

수업용 코드북에서 사용한 코드를 모듈별로 나누어 확인할 수 있다. 전체 프로그램의 흐름을 먼저 보고, 필요한 모듈을 열어 문법과 값의 흐름을 추적한다.

이 코드는 특정 문제에 대한 단 하나의 정답이나 최적해가 아니라, 수업에서 문법·함수 호출·데이터 흐름을 단계적으로 읽을 수 있도록 구성한 교육용 코드다.
