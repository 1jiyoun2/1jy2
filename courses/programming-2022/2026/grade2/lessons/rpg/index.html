텍스트 RPG

Python concepts in a larger program

짧은 예제 코드에서 벗어나 하나의 큰 텍스트 RPG를 읽으며 Python의 여러 요소가 실제 프로그램 안에서 어떻게 연결되는지 살펴본다.

살펴보는 내용

개념코드에서 확인할 점
입력과 출력사용자 입력이 변수에 저장되고 게임 진행에 사용되는 과정
조건문상태와 입력에 따라 실행 경로가 달라지는 구조
반복문게임 진행과 반복 동작을 만드는 구조
함수기능을 작은 단위로 나누고 호출하는 방식
매개변수와 반환값함수 사이에서 값을 전달하고 결과를 돌려주는 방식
자료구조리스트·딕셔너리·집합 등이 게임 데이터 관리에 사용되는 방식
모듈과 구조화코드의 역할을 구분하고 큰 프로그램을 관리하는 방법

코드 전체를 암기하거나 클래스 문법을 학습하는 것이 목적이 아니라, 이미 배운 개념이 규모가 큰 프로그램에서 어떻게 사용되는지를 읽는 데 초점을 둔다. 클래스가 낯설다면 보충 개념: 클래스를 참고한다.
