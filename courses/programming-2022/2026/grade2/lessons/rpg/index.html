전체 코드를 처음부터 모두 이해하는 것이 목표가 아니다. 문법 찾기 → 실행 흐름 추적 → 데이터 흐름 분석의 순서로 읽으며, 함수의 입력·처리·반환값과 객체의 값 변화를 따라가는 데 초점을 둔다. 클래스 문법 자체는 학습 범위로 다루지 않으며, 필요한 경우 보충 개념: 클래스를 참고한다.
