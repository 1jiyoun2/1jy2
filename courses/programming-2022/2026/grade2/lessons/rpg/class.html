보충 개념: 클래스

텍스트 RPG 코드를 읽기 위한 최소한의 개념

이 내용은 2022 개정 프로그래밍 교과서의 핵심 학습 범위로 다루는 내용이 아니다. 텍스트 RPG 코드에 등장하는 구조를 읽을 수 있도록 필요한 만큼만 간단히 설명한다.

클래스는 무엇인가?

관련된 데이터와 기능을 하나의 틀로 묶어 표현하는 방법이다. 여기서는 클래스를 새로 설계하는 방법보다, 이미 작성된 코드 안에서 “어떤 값과 기능이 한 묶음으로 관리되고 있는지” 읽는 데 초점을 둔다.

아주 간단한 예

class Player:
    def __init__(self, name):
        self.name = name
        self.hp = 100

    def show_status(self):
        print(self.name, self.hp)

player = Player("용사")
player.show_status()

코드 읽기

코드 가볍게 이해하기
class Player: 플레이어와 관련된 값과 기능을 묶는 틀
__init__ 플레이어가 처음 만들어질 때 필요한 값을 준비하는 부분
self.name 각 플레이어가 가지고 있는 이름 값
show_status() 플레이어 상태를 보여 주는 기능
Player("용사") Player 틀을 이용해 실제 플레이어 하나를 만드는 부분

텍스트 RPG에서 볼 때

텍스트 RPG에는 플레이어, 게임 진행, 전투, 퀘스트처럼 서로 관련된 값과 기능을 한 묶음으로 관리하기 위해 클래스가 사용된다. 수업에서는 클래스 문법 전체를 배우기보다, “이 부분이 어떤 역할을 맡고 있는가”를 함수와 기능 단위로 읽으면 충분하다.

핵심은 클래스 문법 암기가 아니라, 큰 프로그램에서 관련된 데이터와 기능을 묶어 관리할 수 있다는 점을 이해하는 것이다.
