02. 기획

요구분석명세를 실제 프로그램으로 만들기 위한 전체 방향과 범위를 결정한다.

수업에서 정하는 내용

  • 프로그램 주제와 핵심 기능
  • 필수 기능과 추가 기능의 구분
  • 프로그램의 시작부터 종료까지 큰 실행 흐름
  • 어떤 기능을 함수로 분리할지
  • 각 함수가 어떤 값을 매개변수로 받을지
  • 현재 수업 범위에서 구현 가능한지

주제 선택

교과서의 프로그램 개발 프로젝트 중 하나를 활용하거나 별도의 주제를 정할 수 있다. 어떤 주제를 선택하더라도 요구분석명세·기획·설계·구현·테스트의 흐름과 수업에서 정한 함수·매개변수 사용 조건은 동일하게 적용한다.

기획 단계에서 미리 적어 두기

기능기획에서 확인할 것
입력 기능어떤 값을 입력받는가?
핵심 처리 기능어떤 계산·판단·반복이 필요한가?
함수어떤 기능을 함수로 분리할 것인가?
매개변수함수 실행에 필요한 값을 어떻게 전달할 것인가?
출력 기능처리 결과를 어떤 형태로 보여 줄 것인가?

확인 활동

  1. 핵심 기능을 한 문장씩 나누어 적고, 각각을 함수로 분리할 수 있는지 표시해 본다.
  2. 각 함수에 외부에서 전달되어야 할 값을 찾아 매개변수 후보로 적어 본다.
  3. 요구분석명세에 있는 기능 중 기획에서 빠진 것이 없는지 대조한다.
