프로그램 기획

Program Planning

프로그램 기획은 분석한 요구 사항을 바탕으로 무엇을 만들 것인지 구체적인 방향을 정하는 과정이다. 프로그램의 목적과 대상 사용자를 정하고, 어떤 기능을 제공하며 사용자가 프로그램과 어떻게 상호 작용할지 계획한다.

프로그램 기획서의 주요 내용

항목확인할 내용
프로그램명프로그램의 목적과 성격을 나타내는 이름
목적어떤 문제를 해결하거나 어떤 도움을 제공하기 위한 프로그램인가?
대상 사용자누가 이 프로그램을 사용하는가?
기능 요구 사항입력, 처리, 결과 표시 등 어떤 기능을 제공해야 하는가?
사용자 인터페이스사용자가 값을 입력하고 결과를 확인하는 방식은 어떻게 구성할 것인가?
특징사용 편의성이나 오류 처리처럼 프로그램이 갖추어야 할 주요 특성은 무엇인가?

기획과 요구 분석의 관계

기획은 요구 분석과 분리된 완전히 새로운 단계라기보다, 분석된 요구를 실제 개발 계획으로 구체화하는 과정이다. 요구 사항에서 확인한 목적과 기능이 기획서의 프로그램 목적, 기능 요구 사항, 사용자 인터페이스로 이어진다.

개발 모형

모형특징
폭포수 모형각 단계를 순서대로 진행하고 단계별 결과물을 명확하게 만드는 전통적인 개발 방식
프로토타입 모형견본 프로그램을 만들어 사용자의 요구를 확인하고 반복적으로 수정·보완하는 방식
나선형 모형반복적인 개발 과정에 위험 분석을 포함하여 점진적으로 프로그램을 완성하는 방식
