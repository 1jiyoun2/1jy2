프로그램 구현

Implementation · Coding

구현 단계에서는 설계한 프로그램의 구조와 알고리즘을 프로그래밍 언어로 표현하여 실제 프로그램을 작성한다. 입력, 처리, 출력의 흐름을 구체적인 코드로 옮기고 각 기능이 설계한 대로 동작하는지 확인한다.

구조적 프로그래밍

프로그램 구현에는 순차, 선택, 반복의 기본 제어 구조를 결합하고 중첩하여 사용하는 구조적 프로그래밍 방법을 활용할 수 있다. 실행 과정을 논리적이고 체계적으로 표현할 수 있어 프로그램을 이해하기 쉽고 논리적 오류를 줄이는 데 도움이 된다.

구조역할
순차명령을 정해진 순서대로 실행한다.
선택조건에 따라 실행할 명령을 결정한다.
반복정해진 조건이나 횟수에 따라 같은 처리를 반복한다.

구현에서 확인할 내용

  • 설계한 입력·처리·출력 흐름이 코드에 반영되어 있는가?
  • 알고리즘의 각 단계가 코드에서 대응되는가?
  • 필요한 선택과 반복 구조가 올바르게 사용되었는가?
  • 변수명, 들여쓰기, 주석 등을 통해 코드의 역할을 이해할 수 있는가?
  • 기능별로 실행했을 때 예상한 결과가 나타나는가?

구현은 설계와 분리된 작업이 아니다. 구현 과정에서 설계의 문제를 발견하면 설계를 다시 확인하고 수정할 수 있다.
