04. 구현

설계에서 정한 구조와 알고리즘을 Python 코드로 옮긴다.

구현에서 확인할 내용

  • 설계한 입력·처리·출력 순서가 코드에 반영되어 있는가?
  • 기획·설계에서 정한 기능이 실제 함수로 구현되어 있는가?
  • 함수 실행에 필요한 값이 매개변수를 통해 전달되는가?
  • 조건문과 반복문이 설계한 알고리즘과 같은 흐름으로 동작하는가?
  • 변수명·들여쓰기·주석을 통해 코드의 역할을 읽을 수 있는가?

수업에서 사용하는 구현 방식

처음부터 전체 코드를 한 번에 완성하기보다, 입력 처리 → 핵심 기능 → 출력처럼 작은 기능부터 실행해 보고 연결한다. 함수도 정의만 해 두는 것이 아니라 실제로 호출하여 입력값과 결과를 확인한다.

코드 확인 순서

확인질문
입력입력값이 원하는 자료형과 변수에 저장되는가?
함수 호출어떤 값이 인자로 전달되고 어떤 매개변수에 저장되는가?
처리조건과 반복이 예상한 순서로 실행되는가?
결과반환값 또는 출력값이 다음 단계에서 올바르게 사용되는가?

확인 활동

  1. 작성한 함수 하나를 골라 “입력값 → 매개변수 → 내부 처리 → 결과”의 흐름을 설명해 본다.
  2. 설계서의 알고리즘 한 단계와 실제 코드 한 부분을 서로 연결해 표시한다.
  3. 현재 실행 가능한 가장 작은 기능부터 실행하고 결과를 기록한다.
