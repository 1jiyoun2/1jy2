01. 요구분석명세

프로그램이 왜 필요한지, 무엇을 해야 하는지 먼저 명확하게 기록한다.

작성할 내용

항목확인할 내용
문제와 목적어떤 문제를 해결하며 프로그램을 왜 만드는가?
사용 대상누가 어떤 상황에서 사용하는가?
핵심 기능프로그램이 반드시 수행해야 하는 기능은 무엇인가?
입력사용자가 무엇을 입력하며 어떤 조건을 만족해야 하는가?
출력어떤 결과가 어떤 형태로 출력되어야 하는가?
제약 조건입력 범위, 처리 조건, 반드시 지켜야 할 규칙은 무엇인가?

작성 원칙

  • “편리하게 만든다”처럼 해석이 달라질 수 있는 표현보다 확인 가능한 기능으로 적는다.
  • 한 문장에는 한 가지 요구를 중심으로 작성한다.
  • 나중에 테스트할 수 있도록 입력·처리·출력 조건을 구체적으로 적는다.

확인 활동

  1. 내가 적은 요구 사항만 읽어도 다른 사람이 프로그램의 동작을 예상할 수 있는가?
  2. 각 요구 사항을 구현 후 실제 실행으로 확인할 수 있는가?
  3. 서로 충돌하거나 빠진 요구 사항은 없는가?
