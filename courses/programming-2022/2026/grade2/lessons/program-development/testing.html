05. 테스트

예상 결과와 실제 실행 결과를 비교하고, 발견한 문제를 수정한 뒤 다시 확인한다.

세 가지 관점

테스트수업에서 확인하는 범위
단위 테스트함수나 기능 하나가 주어진 입력에서 예상대로 동작하는지 확인
통합 테스트서로 연결된 여러 기능 사이에서 값 전달과 실행 흐름이 올바른지 확인
시스템 테스트프로그램 전체를 처음부터 끝까지 실행하며 요구 사항을 만족하는지 확인

테스트 기록

“오류 없음”이라고만 적지 않고, 어떤 입력을 사용했고 어떤 결과를 예상했으며 실제 결과가 어땠는지를 남긴다. 문제가 발견되면 원인과 수정 내용을 기록하고 같은 조건으로 다시 실행한다.

기록 항목예
테스트 대상확인할 함수·기능·전체 흐름
입력값정상값, 경계값 등 실제로 사용한 데이터
예상 결과설계상 나와야 하는 결과
실제 결과프로그램을 실행해 확인한 결과
오류·원인예상과 다르면 어느 단계에서 차이가 생겼는지
수정·재검사수정한 뒤 같은 테스트를 다시 실행한 결과

확인 활동

  1. 핵심 함수 하나에 대해 정상 입력과 경계 입력을 각각 정해 테스트해 본다.
  2. 함수 두 개 이상이 연결되는 흐름에서 전달되는 값을 추적해 본다.
  3. 프로그램을 처음부터 끝까지 실행해 요구분석명세의 핵심 기능을 하나씩 확인한다.
