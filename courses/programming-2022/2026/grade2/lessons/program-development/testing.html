프로그램 테스트

Unit Test · Integration Test · System Test

테스트는 구현한 프로그램이 요구 사항을 만족하며 정확하게 동작하는지 확인하는 과정이다. 예상 결과와 실제 실행 결과를 비교하고, 차이가 있으면 원인을 찾아 프로그램을 수정·보완한다.

테스트의 기본 흐름

순서내용
1. 테스트 데이터 준비프로그램의 기능을 확인할 수 있는 입력 데이터를 정한다.
2. 예상 결과 결정설계와 요구 사항을 바탕으로 어떤 결과가 나와야 하는지 미리 정한다.
3. 실제 실행프로그램에 테스트 데이터를 입력하고 실제 결과를 확인한다.
4. 비교와 판단예상 결과와 실제 결과를 비교하여 오류 여부를 판단한다.
5. 수정과 재검사오류가 있다면 원인을 찾아 수정한 뒤 다시 테스트한다.

테스트의 종류

테스트확인하는 범위
단위 테스트프로그램을 구성하는 개별 기능이나 단위가 올바르게 동작하는지 확인
통합 테스트여러 기능을 연결했을 때 데이터 전달과 상호 작용이 올바른지 확인
시스템 테스트전체 프로그램을 실제 실행 환경에서 동작시켜 요구 사항을 만족하는지 확인

테스트 기록

테스트에서는 단순히 “정상 작동”이라고 판단하는 것이 아니라 입력 데이터, 예상 결과, 실제 결과를 근거로 동작 여부를 확인해야 한다. 발견한 오류와 수정한 내용도 함께 기록하면 프로그램의 문제를 추적하기 쉽다.

요구 사항 명세는 테스트의 기준이 된다. 처음에 정의한 기능과 조건이 실제 프로그램에서 충족되는지 확인하는 것이 테스트의 핵심이다.
