03. 설계

코딩하기 전에 입력·출력·데이터·함수·알고리즘을 구현 가능한 수준으로 구체화한다.

설계 요소

설계기록할 내용
입력 설계입력값, 자료형, 범위와 입력 방법
출력 설계출력할 값과 표시 형식
변수·자료구조 설계저장해야 할 값과 사용할 변수·리스트·딕셔너리 등
함수 설계함수 이름, 역할, 매개변수, 필요한 경우 반환값
처리 설계조건·반복·함수 호출이 이어지는 순서
알고리즘순서도 또는 의사 코드 등으로 처리 절차 표현

함수 설계에서 확인할 질문

  • 이 함수는 한 가지 역할로 설명할 수 있는가?
  • 함수 안에서 필요한 값은 무엇이며, 그중 매개변수로 받아야 하는 값은 무엇인가?
  • 함수 실행 후 다른 곳에서 사용할 결과가 있다면 반환값이 필요한가?
  • 함수 호출 순서를 알고리즘에서 확인할 수 있는가?

설계 점검

  1. 설계서만 보고 구현을 시작할 수 있을 정도로 구체적인가?
  2. 요구분석명세의 모든 핵심 기능이 설계에 연결되어 있는가?
  3. 입력 → 처리 → 출력의 흐름 사이에 빠진 단계가 없는가?
