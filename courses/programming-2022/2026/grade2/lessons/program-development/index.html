프로그램의 설계와 구현

Program Development · Requirements · Design · Implementation · Testing

프로그램 개발은 코드를 작성하는 것만으로 끝나지 않는다. 무엇을 만들 것인지 정하고 사용자의 요구를 분석한 뒤, 프로그램의 구조와 알고리즘을 설계하고 구현한 다음 테스트를 통해 동작을 확인하고 수정하는 과정을 거친다.

프로그램 개발 과정

단계학습 내용
요구 사항 분석과 명세사용자의 요구를 수집·분류·분석하고 필요한 기능과 제약 조건을 명확하게 기록
프로그램 기획프로그램의 목적, 대상 사용자, 기능 요구 사항, 사용자 인터페이스 등 개발 방향 결정
프로그램 설계입력·출력과 해결 방법을 정리하고 프로그램의 구조와 알고리즘을 구체화
프로그램 구현설계한 구조와 알고리즘을 프로그래밍 언어로 표현하여 실제 프로그램 작성
프로그램 테스트예상 결과와 실제 실행 결과를 비교하고 단위·통합·시스템 테스트를 통해 오류 확인 및 수정

개발 방법은 하나가 아니다

프로그램 개발 과정은 프로젝트의 성격에 따라 다르게 구성할 수 있다. 단계별로 순차적으로 진행하는 폭포수 모형, 견본 프로그램을 만들고 수정·보완하는 프로토타입 모형, 반복 개발에 위험 분석을 더한 나선형 모형처럼 다양한 방법이 사용된다.
