프로그램의 설계와 구현

Requirements · Planning · Design · Implementation · Testing

프로그램을 바로 코딩하지 않고, 문제와 요구를 먼저 정리한 뒤 기획·설계·구현·테스트를 단계별로 진행한다. 각 단계의 결과가 다음 단계의 근거가 되도록 연결하는 것이 핵심이다.

단계핵심
01. 요구분석명세프로그램의 목적·사용자·필요 기능·조건을 명확하게 기록
02. 기획주제와 기능 범위, 함수·매개변수 사용 계획, 전체 실행 흐름 결정
03. 설계입력·출력·변수·함수·매개변수·알고리즘을 구현 가능한 수준으로 구체화
04. 구현설계를 바탕으로 Python 코드 작성 및 기능 단위 실행 확인
05. 테스트단위·통합·시스템 관점에서 실행 결과를 검증하고 오류 수정

수업에서의 진행 방식

주제를 정한 뒤 모든 산출물을 한 번에 작성하지 않고, 요구분석명세부터 테스트까지 한 단계씩 완성한다. 교과서의 프로젝트 주제를 활용할 수도 있고 별도의 주제를 정할 수도 있지만, 수업에서 정한 공통 구현 조건은 동일하게 적용한다.

공통 구현 조건

  • 프로그램의 기능과 입력·출력이 요구분석명세와 연결되어야 한다.
  • 기획 단계에서 어떤 기능을 함수로 구현할지 미리 정한다.
  • 함수에 필요한 값은 매개변수로 전달하는 구조를 설계한다.
  • 구현 코드는 설계한 알고리즘과 함수 구조를 따라 작성한다.
  • 테스트에서는 실제 입력값과 실행 결과를 근거로 오류 여부와 수정 과정을 확인한다.

이 과정은 하나의 정답 코드를 만드는 활동이 아니라, 자신이 정한 문제를 개발 절차에 따라 설명하고 구현할 수 있도록 구성한 수업이다.
