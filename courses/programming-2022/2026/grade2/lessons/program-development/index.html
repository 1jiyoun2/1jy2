프로그램의 설계와 구현

Program Development Process

하나의 프로그램을 바로 코딩하는 대신, 필요한 기능을 분석하고 개발 과정을 단계별 산출물로 구체화한 뒤 구현과 테스트까지 연결한다.

단계핵심
01. 요구 사항 분석프로그램의 목적과 필요한 기능을 명확하게 정의
02. 기획무엇을 어떤 방식으로 만들 것인지 전체 방향 결정
03. 설계입력·출력·변수·함수·처리 과정과 알고리즘 구체화
04. 구현설계를 바탕으로 Python 코드 작성
05. 테스트실행 결과 검증 · 오류 확인 · 수정 및 보완

교과서의 프로젝트 문제 원문·그림·모범 코드 등 저작권이 있는 내용을 복제하지 않고, 수업에서 사용한 개발 과정과 교사가 직접 작성한 자료만 공개한다.
