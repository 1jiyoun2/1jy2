예외 처리

Exception Handling

프로그램이 항상 예상대로 실행된다는 가정에서 벗어나, 실행 중 발생할 수 있는 예외를 확인하고 프로그램이 적절하게 대응하도록 작성한다.

학습 내용

  • 예외와 일반적인 실행 오류의 의미
  • try / except 구조
  • 입력값 변환 과정에서 발생하는 예외
  • 파일을 읽는 과정에서 발생할 수 있는 예외
  • 예외 발생 상황을 직접 만들고 처리 결과 확인
